# ที่มาของ `docs/Life-OS-User-Manual-TH.pdf`

คู่มือถูกสร้างจากภาพหน้าจอของ **ระบบจริงบน production** ไม่ใช่ภาพจำลอง
ถ่ายด้วย Playwright ที่ viewport ขนาดมือถือ (390×844, DPR 2) โดยล็อกอินด้วยบัญชีผู้ใช้ทั่วไป
ที่ไม่มีสิทธิ์ admin เพื่อให้เห็นเมนูเท่าที่ผู้ใช้ทั่วไปเห็นจริง

## ทำไมต้องพิมพ์ผ่าน Chromium

ภาษาไทยต้องอาศัย OpenType shaping จริงเพื่อวางสระและวรรณยุกต์ให้ถูกตำแหน่ง
ไลบรารี PDF ที่วาดทีละ glyph จะวางซ้อนกันจนอ่านไม่ออก จึงประกอบเป็น HTML
แล้วให้ Chromium พิมพ์เป็น PDF ฟอนต์ Sarabun ฝังเป็น base64 ในไฟล์
ผลลัพธ์จึงไม่ขึ้นกับว่าเครื่องที่รันมีฟอนต์ไทยติดตั้งอยู่หรือไม่

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์             | หน้าที่                                                       |
| ---------------- | ------------------------------------------------------------- |
| `chapters_a.py`  | บทที่ 0-5 — การเข้าใช้งาน, แชท, เอกสาร, งาน, ปฏิทิน, ค้นหา    |
| `chapters_b.py`  | บทที่ 6-9 — เงิน, ครอบครัว, ช่วยฉันที, สิทธิฉัน               |
| `chapters_c.py`  | บทที่ 10-15 — ตัดสินใจ, ของดีใกล้บ้าน, มรดก, แพ็กเกจ, แจ้งเตือน, ตั้งค่า |
| `make.py`        | ประกอบทุกบทเป็น HTML หน้าเดียว ฝังฟอนต์และภาพเป็น base64      |

## วิธีสร้างใหม่

1. ถ่ายภาพหน้าจอใหม่ด้วย Playwright (viewport มือถือ) ลง `img/` เป็น `.jpg` กว้าง 560 px
2. ดาวน์โหลด Sarabun (น้ำหนัก 400/600/700 ชุด thai + latin) แล้วทำเป็น `font.css` แบบ base64
3. `python3 make.py` → ได้ `manual.html`
4. ให้ Chromium พิมพ์เป็น PDF ขนาด A4 `printBackground: true`

เมื่อหน้าจอของระบบเปลี่ยน ให้ถ่ายภาพใหม่แล้วสร้างซ้ำ — อย่าแก้ PDF โดยตรง
