# Life OS Billing Design

## หลักการ

- **Free ตลอดได้** สำหรับฟีเจอร์หลักที่ไม่กิน AI หนัก (เอกสารเก็บ, งาน, ครอบครัว, ฯลฯ)
- **จำกัด AI รายเดือน** บน Free เพื่อคุมต้นทุน
- **Premium / Family** จ่ายรายเดือนหรือรายปี (รายปีถูกกว่า ~17%)
- ฐานราคา: ต้นทุน API × **cost_factor (ค่าเริ่ม 1.18 ≈ +18%)** แล้วบวก **margin (ค่าเริ่ม 20%)** — Admin ปรับได้ที่ `/admin`

## โควต้าฟรี (ค่าเริ่ม — ปรับได้ใน Admin)

| งาน              | ครั้ง/เดือน |
| ---------------- | ----------- |
| แชท AI           | 40          |
| วิเคราะห์เอกสาร  | 12          |
| ช่วยตัดสินใจ     | 8           |
| ถอดเสียง         | 15          |
| **รวมทุกงาน AI** | **60**      |

## ราคาแนะนำ (THB)

| แพ็ก    | รายเดือน | รายปี |
| ------- | -------- | ----- |
| Premium | 89       | 890   |
| Family  | 149      | 1,490 |

เหตุผลคร่าวๆ: ผู้ใช้ฟรีหนัก ~60 ครั้ง/เดือน ต้นทุนอ้างอิงหลัง factor+margin อยู่หลักสิบบาท → ราคา 89 บาทครอบคลุมผู้ใช้หนัก 2–3 คน + ต้นทุนคงที่

## Pay-as-you-go (ตัวเลือก)

- ปิดไว้เป็นค่าเริ่ม (`payg_enabled = false`)
- ถ้าเปิด: เกินโควต้าคิดเป็นสตางค์/ครั้ง (`payg_unit_price_satang` ค่าเริ่ม 50)
- แสดงคำอธิบายในเมนูสนับสนุน

## การชำระเงิน

- PromptPay QR ผ่าน `billing_promptpay_id` (หรือ fallback helpme/funeral)
- ผู้ใช้กด「แจ้งว่าโอนแล้ว」→ เปิดสิทธิ์จนถึง `period_end`
- Admin ตรวจ/ยืนยันเพิ่มได้ภายหลัง

## การบังคับใช้โควต้า

- `checkAndConsumeAiQuota` — เรียกก่อนงาน AI สำคัญ
- Premium ที่ยังไม่หมดอายุข้ามโควต้า
