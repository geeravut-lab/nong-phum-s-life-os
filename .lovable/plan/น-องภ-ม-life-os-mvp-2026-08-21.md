# น้องภูมิ — Life OS (MVP)

สร้างได้ครับ ผมวิเคราะห์จากเอกสารแล้ว: ขอบเขตเต็ม 7 ระบบใหญ่เกินกว่าจะทำรอบเดียว แต่ MVP 5 ฟังก์ชัน + Chat Router ที่คุณเลือก ทำได้จริงบน Lovable และต่อยอดเป็น ecosystem ได้ตามเฟสในเอกสาร

## คำแนะนำเรื่อง Database / Auth / Deploy

- **Database + Auth + File Storage + Server code:** ใช้ **Lovable Cloud** (Postgres + Auth + Storage + serverless ในตัว) แทน Firebase — ไม่ต้องสมัครบริการนอก, มี Row-Level Security ต่อผู้ใช้/ครอบครัว, ข้อมูลเป็นตารางสัมพันธ์ซึ่งเหมาะกับ Life OS (เอกสาร ↔ เตือน ↔ ค่าใช้จ่าย ↔ สมาชิกครอบครัว) มากกว่า NoSQL ของ Firestore
- **AI (OCR/สรุป/จัดหมวด/Chat Router):** ใช้ **Lovable AI** ในตัว ไม่ต้องมี API key เอง
- **Deploy:** ใช้ปุ่ม Publish ของ Lovable (ได้โดเมน .lovable.app + ต่อโดเมนของคุณเองได้) แทน Netlify — เพราะแอปมีโค้ดฝั่งเซิร์ฟเวอร์ที่ deploy พร้อมกันอัตโนมัติ

## บุคลิก "น้องภูมิ"

ผู้ช่วยวัยรุ่นทำงานไว แต่รอบคอบแบบญาติผู้ใหญ่ — พูดสุภาพ กระชับ เรียกผู้ใช้ว่า "พี่", เตือนล่วงหน้าเสมอ, ไม่วินิจฉัย/ไม่ตัดสินใจแทน แต่เสนอทางเลือกและถามยืนยันก่อนบันทึก

## ขอบเขตที่จะสร้าง

1. **เอกสาร (Docs Vault)** — อัปโหลดรูป/PDF → AI อ่าน สรุป จัดหมวด ดึงวันครบกำหนด/จำนวนเงิน/คู่สัญญา → เก็บใน vault พร้อมค้นหา
2. **เรื่องที่ต้องทำ (Reminders)** — สร้างจากภาษาธรรมชาติหรือจากเอกสารอัตโนมัติ, จัดลำดับความสำคัญ, งานที่เกิดซ้ำ
3. **บิล/ค่าใช้จ่าย** — บันทึกรายจ่าย AI จัดหมวด สรุปยอดรายเดือน แนวโน้ม และบิลที่ใกล้ครบกำหนด
4. **ครอบครัว** — สร้างกลุ่มครอบครัว เชิญสมาชิก แชร์เตือน/เอกสารเป็นรายการที่เลือก พร้อมสิทธิ์ผู้ปกครอง/สมาชิก
5. **Daily Brief** — หน้าแรก "วันนี้มี N เรื่องที่พี่ควรรู้" รวมทุกโมดูล
6. **Chat Router** — ช่องคุยกับน้องภูมิ: พิมพ์ภาษาคนแล้วระบบเลือก action เอง (สร้างเตือน / บันทึกค่าใช้จ่าย / ค้นเอกสาร / สรุปวันนี้) แล้วแสดงการ์ดยืนยันก่อนบันทึกจริง

ภาษา: ไทยเป็นหลัก มีสวิตช์ TH/EN ทั้งแอป

## หน้าจอ

```text
/            Daily Brief (หน้าแรกหลังล็อกอิน)
/auth        สมัคร/เข้าสู่ระบบ
/chat        คุยกับน้องภูมิ
/docs        คลังเอกสาร + อัปโหลด + รายละเอียดเอกสาร
/tasks       เรื่องที่ต้องทำ / เตือนความจำ
/money       บิลและค่าใช้จ่าย
/family      ครอบครัวและการแชร์
/settings    โปรไฟล์ ภาษา การแจ้งเตือน ความเป็นส่วนตัว
```

ดีไซน์: mobile-first, การ์ดโค้งมน, โทนอบอุ่นน้ำเงิน-เขียวมิ้นต์ + สีเน้นส้มอ่อน, ฟอนต์ไทยอ่านง่าย (เช่น IBM Plex Sans Thai), รองรับ dark mode

## รายละเอียดทางเทคนิค

- เปิด Lovable Cloud; ตาราง: `profiles`, `families`, `family_members`, `documents`, `document_fields`, `reminders`, `expenses`, `chat_messages`, `activity_log` พร้อม RLS แบบ owner + family-share และ GRANT ครบ; roles แยกตาราง `user_roles` + `has_role()`
- ไฟล์เอกสารเก็บใน storage bucket แบบ private, เข้าถึงผ่าน signed URL
- AI: server functions สำหรับ (a) วิเคราะห์เอกสาร → structured output, (b) chat router → tool calling ไปยัง action ของแต่ละโมดูล, (c) สร้าง Daily Brief
- i18n: dictionary TH/EN ในโค้ด + เก็บภาษาที่เลือกไว้ในโปรไฟล์

## สิ่งที่ยังไม่ทำในรอบนี้ (เฟสถัดไป)

Task Marketplace, สิทธิฉัน, ของดีใกล้บ้าน, Decision Board, การชำระเงิน, LINE notification, Admin dashboard — โครงข้อมูลจะออกแบบให้ต่อยอดได้
